# Domain Context: Taiwan Earthquake Model & Datasets

## 1. Overview
The **Taiwan Earthquake Model (TEM)** project aims to improve earthquake science and hazard mitigation in Taiwan through multidisciplinary research, integrating seismology, geology, and earthquake engineering.

---

## 2. Core Datasets in `data/raw/`

### 2.1 Fault Alignments (`Fault Alignments.xlsx`)
- Geographic traces and geometry alignments of active fault systems across Taiwan.
- Key features: Fault identification, segment coordinates, geometry representations.

### 2.2 Fault Parameters (`Fault Parameters_update.xlsx`)
- Geotechnical and seismological fault characteristics.
- Attributes: Strike, dip, rake, locking depth, slip rate (mm/yr), characteristic magnitude ($M_w$), recurrence intervals.

### 2.3 TEM PSHA 2025 (`TEM PSHA2025-draft.pdf`)
- Probabilistic Seismic Hazard Assessment 2025 draft report.
- Contains hazard curves, ground motion models (GMMs), seismogenic source models, and hazard maps for Taiwan.

### 2.4 Ground Motion Deep Learning (`Journal of Geophysical Research...pdf`)
- Study: *Chen et al. (2026) - A Deep Learning Framework for Peak Ground Motion Prediction*.
- Demonstrates machine learning frameworks predicting peak ground acceleration (PGA) and velocity (PGV) under Taiwan tectonic settings.
